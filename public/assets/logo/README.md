# Logo Inovaxio - arquivos

Exporte os arquivos do logo com estes nomes exatos. O site já aponta para eles;
assim que caírem aqui, aparecem no brandbook (Sistema Visual > Logo) e na
Central de Recursos (downloads).

Preferência de formato: **SVG** para tudo (vetorial, escala sem perda). Gere
também **PNG @2x** (fundo transparente) para uso em Office, e-mail e apresentacoes.

## Símbolo isolado

| Arquivo | Descrição |
|---|---|
| `simbolo-cor.svg` | Símbolo em azul da marca (#2E2EFE), fundo transparente |
| `simbolo-branco.svg` | Símbolo em branco, para fundos escuros |
| `simbolo-preto.svg` | Símbolo em preto, para fundos claros |

## Assinatura horizontal (símbolo + INOVAXIO ao lado)

| Arquivo | Descrição |
|---|---|
| `inovaxio-horizontal-cor.svg` | Símbolo azul + wordmark preto, fundo claro |
| `inovaxio-horizontal-preto.svg` | Tudo preto, fundo claro |
| `inovaxio-horizontal-branco.svg` | Tudo branco, fundo escuro (negativo) |

## Construção (diagramas de referência)

| Arquivo | Descrição |
|---|---|
| `construcao-grid.png` | Grid de construção do símbolo (o desenho com b / A) |
| `construcao-aurea.png` | Proporção áurea sobre o símbolo |

## Também gerar (PNG @2x, transparente)

Mesmos nomes, extensão `.png`, para os que precisam de raster:
`simbolo-cor.png`, `inovaxio-horizontal-cor.png`, `inovaxio-horizontal-branco.png`,
`inovaxio-vertical-branco.png`, `inovaxio-horizontal-preto.png`.

## Depois de exportar

Solte os arquivos nesta pasta com os nomes acima. Nada mais precisa mudar no
código: os placeholders viram os logos reais automaticamente.
