# Proibições do logo

As 6 imagens de uso incorreto do logo (Sistema Visual > Logo > Proibições).
Cada uma mostra o erro que o texto do card descreve. PNG, fundo do exemplo.

| Arquivo | Erro mostrado |
|---|---|
| `proibicao-1.png` | Logo distorcido / esticado |
| `proibicao-2.png` | Logo recolorido fora da paleta |
| `proibicao-3.png` | Logo rotacionado |
| `proibicao-4.png` | Logo com sombra, brilho ou efeito |
| `proibicao-5.png` | Logo sobre fundo de baixo contraste |
| `proibicao-6.png` | Logo recriado com outra fonte ou contorno |

Solte os arquivos com estes nomes e eles aparecem nos cards de proibição.
