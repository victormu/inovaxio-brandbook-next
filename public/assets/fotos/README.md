# Fotografia aprovada

As fotos da galeria (Sistema Visual > Fotografia). JPG ou WebP, proporção
paisagem (16:9), fundo real, sem stock genérico. O site já aponta para estes
nomes; solte os arquivos aqui e eles aparecem.

| Arquivo | Atributo |
|---|---|
| `atributo-pratico.jpg` | Prático (equipe técnica em trabalho real) |
| `atributo-tecnico.jpg` | Técnico (desenvolvedor concentrado) |
| `atributo-proximo.jpg` | Próximo (conversa consultor e cliente) |

Recomendação: exporte em ~1600px de largura, otimizado (WebP se possível).
