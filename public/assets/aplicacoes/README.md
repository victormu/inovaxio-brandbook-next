# Mockups de Aplicações da marca

Os exemplos faça / não faça de cada ponto de contato (Sistema Visual >
Aplicações da marca). JPG ou WebP. Cada peça tem um par: `-do` (correto) e
`-dont` (incorreto). Solte os arquivos com estes nomes exatos.

## Digital

| Arquivo | |
|---|---|
| `redes-do.jpg` / `redes-dont.jpg` | Redes sociais (avatar) |
| `email-do.jpg` / `email-dont.jpg` | Assinatura de e-mail |
| `apresentacao-do.jpg` / `apresentacao-dont.jpg` | Apresentações (slide) |

## Físico

| Arquivo | |
|---|---|
| `papelaria-do.jpg` / `papelaria-dont.jpg` | Cartão de visita |
| `documentos-do.jpg` / `documentos-dont.jpg` | Documentos e licitação |
| `sinalizacao-do.jpg` / `sinalizacao-dont.jpg` | Sinalização e ambiente |
| `brindes-do.jpg` / `brindes-dont.jpg` | Brindes e uniforme |

Recomendação: mockups em proporção paisagem, ~1200px de largura.
